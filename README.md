## 🚀 Projetos em Destaque

### 📊 [Monitoramento de Ações B3](https://github.com/BruninSouza/Monitor-B3)
* **O que é:** Dashboard interativo para monitoramento em tempo real de ativos da bolsa de valores brasileira.
* **Tecnologias:** Python, Streamlit, APIs Financeiras e bibliotecas de visualização de dados.
* **Destaque:** Implementação de indicadores técnicos e visualização dinâmica para suporte à tomada de decisão em investimentos.

### 📈 [Análise Preditiva de Dados - Projeto Steam](https://github.com/BruninSouza/Analise-Steam)
* **O que é:** Projeto de Data Science focado em prever tendências de mercado dentro da plataforma Steam.
* **Tecnologias:** Python (Pandas, Scikit-learn, Matplotlib, Seaborn).
* **Impacto:** Análise de mais de **80 mil registros**, resultando em um modelo preditivo para identificação de padrões de comportamento de usuários e vendas.

### 🐍 [Aprenda Python (Open Source)](https://github.com/BruninSouza/Ensino-Python)
* **O que é:** Plataforma de ensino interativa hospedada no GitHub Pages e integrada ao Google Colab.
* **Objetivo:** Facilitar o aprendizado de programação mobile-first, sem necessidade de instalação local.
* **Destaque:** Utilização de Jupyter Book para criar uma documentação técnica limpa e acessível.
