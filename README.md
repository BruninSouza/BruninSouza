## 🚀 Projetos em Destaque

### 📊 [Monitoramento de Ações B3](https://github.com/BruninSouza/Monitor-B3)
* **O que é:** Dashboard interativo para monitoramento em tempo real de ativos da bolsa de valores brasileira.
* **Tecnologias:** Python, Streamlit, APIs Financeiras e bibliotecas de visualização de dados.
* **Destaque:** Implementação de indicadores técnicos e visualização dinâmica para suporte à tomada de decisão em investimentos.

### 📈 [Análise Preditiva de Dados - Projeto Steam](https://github.com/BruninSouza/Analise-Steam)
* **O que é:** Projeto de Data Science focado em identificar padrões de comportamento de usuários e vendas na plataforma Steam.
* **Tecnologias:** Python (Pandas, Scikit-learn, Matplotlib, Seaborn).
* **Impacto:** Análise exploratória e preditiva sobre mais de **80 mil registros**.

### ☕ [Spring Cursos](https://github.com/BruninSouza/Spring-Cursos)
* **O que é:** Aplicação backend desenvolvida para as disciplinas de Desenvolvimento de Software Corporativo e Sistemas Distribuídos.
* **Tecnologias:** Java, Spring Boot, APIs RESTful.
* **Destaque:** Estruturação de uma arquitetura corporativa aplicando boas práticas de sistemas distribuídos.

### 🐍 [Aprenda Python (Open Source)](https://github.com/BruninSouza/Aprenda-Python)
