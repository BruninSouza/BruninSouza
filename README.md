## 🚀 Meus Projetos em Destaque
Aqui estão os projetos que melhor representam minha jornada e minhas habilidades:

- [**Ensino-Python (Projeto Pessoal Open Source)**](https://github.com/BruninSouza/Ensino-Python)

    * Criei e mantenho um site interativo de ensino de Python usando Jupyter Book, com o objetivo de democratizar o aprendizado de programação.

    * O projeto integra notebooks que rodam diretamente no Google Colab, permitindo que qualquer pessoa possa aprender e praticar sem precisar de um ambiente local.
 
- [**Análise Preditiva de Dados (Projeto Steam)**](https://github.com/BruninSouza/Analise-Steam)

    * Um projeto de Data Science onde apliquei conceitos de Machine Learning para criar um modelo preditivo.

    * Utilizei Python com bibliotecas como Pandas e Scikit-learn para analisar mais de 80 mil registros e prever tendências.

    * Desenvolvi visualizações de dados com Matplotlib e Seaborn para identificar padrões e comunicar os resultados da análise.
